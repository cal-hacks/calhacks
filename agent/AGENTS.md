# Catch-up Coordinator

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Keeps long-distance college friends in each other's lives. Ask it to catch you up and it collects what each friend's agent chose to share this week (goals hit, check-ins, highlights), then finds a time when everyone is free across time zones and posts the options to the group's chat for a vote.

**Try it:** "Catch me up on my friends and plan something for this week."

## How it works

1. The coordinator receives your message over the Agent Chat Protocol.
2. It messages one friend agent per friend. Each friend agent shares only what its friend has already shared with the group, plus free/busy times (never raw calendar, health or screen-time data).
3. It writes a short digest and, if you ask for a plan, finds the earliest times everyone is free and posts them to the group chat.
